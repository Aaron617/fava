# Fava 中文帮助分支

这是 [beancount/fava](https://github.com/beancount/fava) 的分支，基于 `v1.30.16`，为内置帮助提供简体中文版本。Fava 和 Beancount 的开源许可不变。

## 已覆盖

9 篇内置帮助：帮助首页、账本语法、预算、币种与估值转换、导入、扩展、功能说明、筛选记录、配置选项。

帮助首页增加了家庭记账常用名词、收入负数和交易状态标记的解释。原有英文文档、代码示例和链接锚点保留。

## 使用

在账本中设置：

```beancount
2026-01-01 custom "fava-option" "language" "zh_CN"
```

启动本分支的 Fava 后打开侧边栏“帮助”。未显式设置语言时，也支持通过浏览器语言选择简体中文。没有对应译文的页面和其他语言继续显示英文。

中文源文件位于 `src/fava/help/zh_CN/`。英文源文件仍在 `src/fava/help/`。

## 收入显示为正数

如希望在损益表和资产负债表中把收入、负债和权益翻转为通常更易理解的正数，可设置 Fava 已有的选项：

```beancount
2026-01-01 custom "fava-option" "invert-income-liabilities-equity" "true"
```

这只改变汇总报表显示，不改变交易金额，日记账和账户明细仍使用原始记账符号。

## 范围与维护

本次翻译覆盖软件内置帮助。外部 Beancount 网站、开发者 API 网站和更新日志尚未完整翻译；链接旁保留原始去向。

译文标题顺序应与英文文档一致，以保留英文锚点和已有深链接。配置键、API 名称、代码示例保持原样；解释文字使用中文。更新英文文档后，应同步调整译文并运行：

```sh
pytest tests/test_help.py tests/test_help_zh_cn.py
```

本仓库只保存软件及通用文档，不包含个人账本、账单或交易信息。
